# Pixel Font Knife

[![Python](https://img.shields.io/badge/python-3.12-brightgreen?style=flat-square)](https://www.python.org)
[![PyPI](https://img.shields.io/pypi/v/pixel-font-knife?style=flat-square)](https://pypi.org/project/pixel-font-knife/)

A toolkit for pixel font build pipelines, providing monochrome and RGBA bitmap
processing, PNG glyph asset management, cmap and fixed-name glyph organization
with multiple flavors, reference mappings, and kerning data generation. It can be
used with [Pixel Font Builder](https://github.com/TakWolf/pixel-font-builder).

## Installation

```shell
pip install pixel-font-knife
```

## Dependencies

- [unicodedata2](https://github.com/fonttools/unicodedata2)
- [Unidata Blocks](https://github.com/TakWolf/unidata-blocks)
- [PNG - Python](https://github.com/TakWolf/png-python)
- [PyYAML](https://github.com/yaml/pyyaml)
